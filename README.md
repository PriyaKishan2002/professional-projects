## 1. STEM Robotics Desktop Application

**Technologies:** Electron, React, TypeScript, Redux, Blockly, Monaco Editor, Node.js, SerialPort, WebSocket

### Overview
A desktop-based STEM robotics application that provides a visual programming environment for users to create programs and interact with robotics hardware.

### Key Contributions
- Developed and maintained application features using React and TypeScript.
- Integrated Blockly for drag-and-drop visual programming.
- Worked with Electron's main process, preload scripts and IPC communication to integrate desktop functionality.
- Implemented wired hardware communication using the SerialPort npm package.
- Worked on wireless device communication using WebSocket connections.
- Managed serial port operations, including port listing, connecting, disconnecting, sending and receiving data.
- Improved serial monitor performance through data buffering and optimized UI updates.
- Contributed to application customization for different client organizations through white-label builds.
- Worked on code editor functionality for Python and C++ programming.

## 3. STEM Robotics Web Application

**Technologies:** Next.js, React, TypeScript, Redux, Blockly

### Overview
A browser-based version of the STEM robotics desktop application, developed from scratch using Next.js to extend the existing application experience to the web for a client.

### Key Contributions
- Developed the web application using Next.js, adapting the existing desktop application functionality for browser environments.
- Reused existing React components and Blockly implementation from the desktop application.
- Used Next.js Client Components with the `'use client'` directive for interactive and browser-dependent functionality.
- Adapted image component rendering to support the web environment.
- Worked on integrating existing visual programming functionality into the web application.
- Addressed compatibility differences between the Electron desktop environment and the browser environment.
